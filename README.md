
# PinkFlow — Flower & Gifts

## Informasi Proyek
- Nama proyek: Website Katalog PinkFlow
- Nama mitra: Rumah Buket PinkFlow
- Pemilik mitra: Imelda
- Mata kuliah: Project Mandiri
- Tahun: 2026

## Deskripsi
PinkFlow merupakan website katalog bunga dan hadiah yang membantu pelanggan melihat pilihan produk serta menghubungi pemilik untuk konsultasi dan pemesanan buket custom.

## Tech Stack
- HTML
- CSS
- PHP Native
- MySQL
- XAMPP
- Visual Studio Code

## Struktur Direktori
- assets/css/ : stylesheet
- assets/js/ : JavaScript
- assets/images/ : gambar dan foto produk
- assets/icons/ : ikon
- assets/fonts/ : font lokal
- config/ : konfigurasi koneksi database
- database/ : file SQL
- includes/ : komponen halaman bersama
- pages/ : halaman website
- index.php : halaman utama

## Cara Menjalankan Secara Lokal
1. Instal dan buka XAMPP.
2. Jalankan Apache dan MySQL.
3. Simpan folder proyek di C:\xampp\htdocs\PinkFlow_ProjectMandiri.
4. Buka phpMyAdmin melalui http://localhost/phpmyadmin/.
5. Buat database bernama pinkflow_mandiri.
6. Impor database/pinkflow_mandiri.sql jika tabel belum tersedia.
7. Periksa pengaturan koneksi pada config/database.php.
8. Buka http://localhost/PinkFlow_ProjectMandiri/.

## Catatan
Database awal menggunakan tabel products dan users.
Sesuaikan isi database dan fitur website selama proses pengembangan.
